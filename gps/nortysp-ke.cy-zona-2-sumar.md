# Súhrn: nortysp-ke.cy-zona-2.kml

## Ako som to spravil

1. Načítal som 99 bodov z pôvodného súboru (jeden priečinok "KE.CY Zona 2", ktorý obsahoval zóny 1–4).
2. **Zóna** som každému bodu priradil podľa polohy a poradia v súbore (1 zelená, 2 žltá, 3 červená, 4 modrá; trasy podľa `KECY mapy/ke.cy-mapy.md`).
3. **Kategóriu** som určil z kódov značenia: MC/MZ = mapy, T = začiatok trailu, SĽ/SP/SR/SV = smerovníky, K/KP = koniec a protismer, ! = výstraha, križovanie a prechod medzi zónami.
4. **Názvy** som opravil (preklepy, diakritika, napr. Surway → SuRAWy, Bedla → Bedľa) a pôvodný názov som nechal v popise.
5. **Popis** každého bodu: Zóna, Typ, Obsah (rozpísané značky), Poznámka, ⚠ pri nejasných bodoch, GPS, Pôvodný názov, maphub-meta.
6. Body som uložil do priečinkov Zóna → kategória, so zdieľanými štýlmi (farba a ikona podľa kategórie). Originál: `nortysp-ke.cy-zona-2.original.kml`.
